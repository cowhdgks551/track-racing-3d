# TRACK RACING 3D

국내 서킷을 배경으로 한 3D 온라인 레이싱 게임 프로토타입입니다. Three.js 클라이언트와 Express/WebSocket 서버로 구성되어 있으며 PC 브라우저와 모바일 브라우저 조작을 지원합니다.

## 구현된 기능
- 3D 후방 추적 카메라와 차량 주행
- 키보드(WASD/방향키) 및 터치 버튼 조작
- 방 코드 기반 실시간 멀티플레이
- 개인전 / 팀전 선택
- 레드팀 / 블루팀 직접 선택, 팀별 최대 5명 (전체 최대 10명)
- 3랩 레이스 및 완주 순위 기록
- 완주 순위 점수: 1위 10점, 2위 9점 … 10위 1점
- 미완주자는 DNF 및 0점으로 결과에 별도 표시
- 팀전은 전체 완주 순위 점수를 팀별로 합산
- 서킷 4종 및 차량 클래스 4종 선택
- 혼자 연습 모드

## 서킷
- 코리아 인터내셔널 서킷 (영암, 5.615 km)
- 인제 스피디움 (3.908 km)
- 에버랜드 스피드웨이 (4.346 km)
- 태백 스피드웨이 (2.5 km)

**트랙 데이터 안내:** 현재 게임 내 트랙은 각 서킷의 형태를 참고해 만든 플레이 테스트용 단순화 레이아웃입니다. 실제 공식 측량 좌표, 정확한 코너 반경, 고저차 및 노면 형상을 그대로 재현한 CAD 수준 모델은 아닙니다. 정밀 재현 단계에서 공식 트랙 도면을 기준으로 중심선 좌표와 폭, 고저차를 보정해야 합니다.

## 차량 클래스
- 가속형: 초반 가속 특화
- 최고속도형: 최고속도 특화
- 코너링형: 조향/코너 안정성 특화
- 밸런스형: 종합 능력 균형

## 로컬 실행
Node.js 20 이상 권장.

```bash
npm install
npm run dev
```
Vite 개발 서버가 브라우저 주소를 표시하며, WebSocket 서버는 `localhost:3000`에서 실행됩니다.

## Render 배포
1. GitHub 저장소를 Render에 연결합니다.
2. Render에서 **New → Blueprint**를 선택합니다.
3. 저장소의 `render.yaml`을 사용해 서비스를 생성합니다.
4. 배포된 HTTPS 주소로 접속합니다. 브라우저는 WSS로 연결합니다.

## Android 패키징
현재는 반응형 웹 프로토타입입니다. APK/AAB 배포는 Capacitor와 Android Studio 설정 및 기기 테스트를 거쳐야 합니다.
